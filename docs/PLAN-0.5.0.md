# Codex Forge 0.5.0 实施与验收

用户授权：先适配新版官方客户端，再加入中文本地化、Ultrafast、插件/浏览器/电脑操作和独立更新器；Forge 版本 0.5.0，API 保持 3。

1. 从官方源获取 26.1103.4239.0，核对签名、包身份、版本与摘要；生成精确适配器，验证冷启动侧栏、工具栏、设置和搜索。
2. 中文本地化：启用原生语言选择，补齐缺失中文和原生菜单，保留其他语言。
3. Fast 模型插件：加入 Ultrafast 配置与模型能力识别，贯通设置、原生选择和请求；尊重模型服务的支持情况。
4. 浏览器插件：加入原生插件、浏览器、电脑操作的可用性支持与 Windows 绑定；保持本地授权边界，并验证开关关闭后的行为。
5. 独立更新器：保留常规客户端升级，失败切换并保留手动备用入口；Forge 自有清单、续传、下载校验、代理设置、完整包/增量选择、独立救援入口；兼容现有 MSI/便携分发，原生官方更新不得覆盖 Forge。
6. 更新 README 的功能介绍、独立更新文档及 CHANGELOG；构建安装包，在隔离目录验收并记录实际验证范围。

参考：AnLifeX/CodexDesktop-Rebuild，调研固定提交 46b7c54。实现遵循 Forge 现有结构；参考项目无独立许可证文件，不直接引入其大段实现。

验证：针对性行为测试、全量回归、真实官方资源补丁检查、安装包内容/摘要检查、隔离客户端交互。真实服务端速度、额度和账号权限不由本地测试证明。

状态：实现与本地验收完成；发行版本为 0.5.0 / API 3，[安装包与发布说明](https://github.com/HOMEFTW/codex-forge/releases/tag/v0.5.0)。常规升级保持默认，独立更新器只作可选入口及失败回退。正式客户端未被测试安装替换。实际测试及限制见 [验证记录](VALIDATION.md#050-本地验收2026-11-09)。
