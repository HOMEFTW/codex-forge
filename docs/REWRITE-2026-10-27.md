# 统计、记忆与独立 500K 重写

## 信息统计

右侧面板按会话概览、模型检测、检测历史分层。概览显示端到端输出速度（包含首 Token 等待与推理）、加权均速、缓存输入、推理输出、最近响应，以及日志实际报告的可用窗口和最近请求占用。累计输入不当作当前上下文使用量。

被动检查读取 turn_context、thread_settings_applied、token_count。对模型切换、思考强度降低、同模型窗口缩小及内部模型记录提供可追溯事件；明确设置变更和未见设置记录分别展示。复制历史不产生告警，服务端身份不由日志或数字概率认证。

保留经源码对照的 ModelTrace 全局算法、18 模型指纹库、1–3 组样本校准、手动粘贴、临时分支采样、取消、24 小时过期及本地历史。修复切换会话时旧异步请求复用状态的问题。准确上游提交见 plugins/forge.information-stats/SOURCES.md。

## 记忆管理

重写列表/编辑器，增加来源筛选、分类计数、名称/修改时间排序、分批展示、备注重命名、快捷保存、文件版本冲突提示。切换文件与筛选保留面板内草稿，关闭时提示未保存内容。生成摘要、历史和技能说明保持只读；新增备注由后续记忆整理处理，不承诺立即注入现有对话。

修复隐藏文件导致遍历 break、目录中间链接、创建同名文件覆盖竞争；保留路径白名单、符号链接限制、内容 hash 乐观并发和原子保存。正文缓存按文件版本失效并有条数/体积上限。

## 500K 根因和修复

原实现仅保留已有 model_catalog_json，默认启动不会生成目录。检查时用户 config.toml 没有该项，models_cache.json 也没有 gpt-6.1-sol 条目，只有 272,000 的 gpt-6-sol，因此说明与探针并不能保证正式启动生效。

现在 Electron 早期启动生成 CODEX_HOME/forge/model-catalog-500k.json（遵循 CODEX_FORGE_HOME），原生网络适配器通过 -c model_catalog_json 注入，数字检测进程继承同一目录。仅 gpt-6.1-sol 设置 500,000，95% 可用窗口为 475,000；其他模型条目不变，不修改用户 config.toml 和 models_cache.json。缺少 6.1 条目时复用 6-sol 能力描述，并保留实际 API 模型名 gpt-6.1-sol。目录不可用时输出明确启动诊断。

## 左栏底部信息卡（截图追加需求）

在原生侧栏账号区上方加入紧凑卡片，显示当前对话最近响应的 Agent 速度（tok/s）和检测候选模型名称。点击或键盘激活打开右侧信息统计面板。原生侧栏使用 data-sidebar-navigation-root 定位；优先挂入原生底部容器，由其已有 ResizeObserver 为卡片和账号区预留高度，旧布局退回侧栏内定位。展开、窄栏、隐藏和窗口缩小时同步适配。

仅当前且未过期的 MISMATCH 使指纹文字变红；弱证据、未收录及过期结果显示对应状态，避免误报。指纹来自已有检测样本，不自动发起付费检测。速度沿用日志记录的最近响应统计，并在提示中注明口径。快照 IPC 绑定 threadId，切换对话增加请求代次，防止离开再返回时旧结果覆盖当前卡片。
