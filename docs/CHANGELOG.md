## 0.5.0

（2026-11-09，API 3），适配官方 Windows x64 客户端 `26.1103.4239.0`。

- 更新 26 个前端工厂和后端适配，修正新标签页布局参数，验证冷启动入口、设置及搜索。
- 启用原生语言选择；沿用官方中文目录并补齐 69 条新版桌面文本。
- Fast 与模型配置加入独立 `ultrafast` 服务档位、默认速度及自定义服务支持的模型 ID；保留原生模型目录、加载状态与受管策略。
- 浏览器插件扩展为“插件、浏览器与电脑操作”，提供独立开关及 Windows CUA 应用绑定。原生权限、平台、WSL 和账号策略继续有效。
- 保留原客户端升级流程，失败时切换独立更新器，也可手动选择。独立更新器支持 HTTP 代理、断点续传、摘要校验、完整/增量链选择及故障回退；支持 MSI 与便携安装、同版本修复，拒绝已启用插件不兼容的更新。
- 安装器保留前一客户端，更新器保留前一配置指针。安装包仍不包含官方客户端。
- [下载安装包](https://github.com/HOMEFTW/codex-forge/releases/tag/v0.5.0) · [更新器说明](UPDATER.md) · [验证范围](VALIDATION.md)。

## 0.4.3

（2026-11-04，API 3）

- **客户端适配**：目标更新为官方 Windows x64 MSIX `26.1029.7803.0`，固定包已核对身份、大小、SHA-256 和发布者签名。
- **原生页面**：适配新的 Rspack 模块结构，在主页面工作区记录侧栏作用域，保留冷启动、切换对话、内置与外部插件标签、全宽和关闭操作。
- **设置与 Fast**：更新设置导航、标题、图标与插件深链接；覆盖全部 9 份 Fast 模块副本，保持插件开关、认证加载状态和受管限制。
- **兼容检查**：按官方 ASAR、EXE 及模块源码摘要匹配补丁，未知客户端拒绝构建。五个历史适配器保留；Forge API 仍为 3，第三方插件须单独声明新客户端兼容性。
- **独立插件覆盖升级**：直接导入同 ID 的新版或同版本修订 ZIP、7z、JSON 包或目录，无需卸载。更新暂存至重启生效，保留设置、数据和启停状态；权限或网络访问范围变化需重新启用。拒绝降级和不兼容包，失败保留旧版。本次保持 Forge 0.4.3、API 3 和客户端版本不变。
- **完整视图**：修复星枢等扩展面板与内置页面完整视图被悬浮侧栏按钮、原生聊天输入条和 Windows 设置提示遮挡的问题；退出完整视图后恢复，其他原生标签不受影响。
- [下载 0.4.3 安装包与便携版](https://github.com/HOMEFTW/codex-forge/releases/tag/v0.4.3)。星枢需另行安装，配套新版客户端请使用独立插件 0.2.1 或声明兼容的后续版本。

## 0.4.2

（2026-11-04，API 3）

- **无需手动解压**：插件管理的“导入插件包…”直接选择 `.zip`、`.7z` 或 `.forge-plugin.json`。自动识别根目录或单个外层目录中的插件，审阅权限后启用；解压器随 Forge 提供。
- **侧栏图标**：扩展贡献支持受限 SVG 路径图标，跟随左侧栏展开、折叠和重新挂载；位置由插件声明，星枢移除工具栏贡献后仅在左侧显示入口。
- **DataviewJS 扩展**：可选 `nexus.script` 权限允许独立插件创建隔离 Worker。星枢 0.2.0 在用户点击“运行此查询”后支持常用只读子集；宿主/MCP 不执行 JavaScript，Worker 不获得 Node、SDK、文件写入或网络权限。
- [下载 0.4.2 安装包与便携版](https://github.com/HOMEFTW/codex-forge/releases/tag/v0.4.2)。独立星枢包需另行安装，不包含在 Forge 安装包内；已有旧星枢可先卸载再导入新版，卸载保留设置。

## 0.4.1

（2026-11-04）

- **Nexus 是独立插件**：Forge 不再包含其界面、固定入口或内置清单。插件 ID 为 `homeftw.nexus`，单独导入、审阅权限、启用和卸载；Forge 只提供 `nexus` 服务和 API 3。
- **插件包导入**：插件管理新增“导入插件包…”，支持 `.forge-plugin.json`；目录安装仍可用，导入默认停用。CLI `install` 同时接受插件目录与包文件。
- **目录连接**：SDK `nexus.connect()` 通过原生选择器连接目录，`disconnect(vaultId)` 断开；二者需要读写权限，不接受插件传入根路径，不开放给 MCP。
- **工具生命周期**：`nexus_*` 仅在 `homeftw.nexus` 已安装、指纹匹配、已启用且具备相应权限时提供。已连接目录保留在宿主数据中，卸载插件不删除笔记。
- **媒体边界**：获得 `nexus.read` 的外部面板可展示 data URL 音视频；PDF 内嵌仍不开放。独立插件最低要求 Forge 0.4.1，API 保持 3，已发布 0.4.0 保留。

## 0.4.0

（2026-11-04）

- **Forge API 3**：保留现有操作，增加可选能力协商、明确的错误码和 Nexus 方法类型。缺少可选能力不再停用整个插件；每次调用继续校验权限和服务启用状态。
- **星枢 Nexus**：首次提供本地知识库功能，0.4.0 当时以内置插件集成，0.4.1 起拆为独立插件。支持 Markdown 编辑与预览、双链/搜索/图谱、属性/任务、Base 数据库、安全 Dataview 查询、模板/日记/QuickAdd 和历史恢复，无需运行 Obsidian。当前安装方式和限制见 [使用说明](NEXUS.md) 与 [接口](NEXUS-API.md)。
- **访问边界**：目录由用户在原生界面选择；插件使用 `nexus.read` / `nexus.write`，模型工具使用 `nexus_`。写入核对修订并保留恢复副本；不执行知识库脚本、宏或系统命令。
- **迁移**：0.3.x/0.2.x 首次升级需手动下载安装包，旧 API 1/2 插件保留数据及诊断，作者迁移后再启用。详见 [API 3 迁移](API-3-MIGRATION.md)。官方客户端目标仍为 26.1027.6604.0。

## 0.3.4

## 0.3.3

- **模型显示控制**：在“设置 → Codex Forge 插件设置 → Fast 与模型配置”勾选对话中可选择的模型，支持恢复默认显示，至少保留一个可选模型；隐藏不删除描述，也不改变已有对话。
- **GPT-6.1-Terra**：补齐原生模型切换菜单与 Fast 档位。请求使用准确的 `gpt-6.1-terra` 标识，Fast 对应 `service_tier: priority`，支持恢复普通速度及切换回其他模型。
- 已有 Terra 描述保留自定义能力和上下文；缺少时使用兼容 Terra/Sol 描述补齐，推理档位按[官方模型说明](https://developers.openai.com/api/docs/models/gpt-6.1-terra)设为 none、low、medium、high、xhigh、max。兼容描述沿用 Codex 的上下文默认值，Sol 独立 500K 不应用到 Terra。
- 仍使用 Forge 专用覆盖目录，保留用户配置及原模型缓存。模型目录在启动时加载，更新后需完整退出并重新启动客户端；实际 Fast 可用性与计费由服务商决定。以上功能统一由“Fast 与模型配置”插件管理；停用并重启后停止应用模型隐藏和 Terra 补齐，保留已保存设置。Sol 独立 500K 继续生效。

## 0.3.2

- **新版客户端适配**：新增 `26.1027.3384.0` 固定适配器，更新主页面工作区、设置导航、Fast 控件及新版后端模块；九个内置插件和示例同步加入兼容声明。
- **主页面按钮**：在新版客户端实际承载聊天工作区的模块中登记原生侧栏，冷启动和切换对话后均可打开左栏及工具栏的 Forge 页面，无需先进入设置。
- **指纹检测隔离**：三份样本分别使用独立临时会话及空工作目录，不复制主任务历史与项目指令；保持当前模型、提供商与思考强度，继续拒绝实际工具调用。计划、压缩和评审状态事件不再误报为工具调用。
- **异常清理**：关闭检测进程后清理临时目录，避免 Windows 目录占用覆盖原始错误。

验证覆盖自动回归、实际官方模块构建及新版 CLI 的本地模拟协议。测试环境中，适配版与未修改的官方版都在窗口出现前以 `0x80000003` 退出，尚未完成真实桌面点击验收；详见[验证记录](VALIDATION.md)。

## 0.3.1

- **新版客户端适配**：新增固定版本适配器，更新原生右侧标签、设置入口、Fast 控件及后端注入点；保持 Forge API 2，九个内置插件及示例同步兼容新客户端。
- **指纹检测修复**：不再用磁盘回合状态选择 `lastTurnId`，避免把运行中的回合误当作已中断回合；直接校验临时分支创建响应，避免后续读取的空来源 ID 覆盖正确结果。
- **检测清理**：校验失败、取消和异常时释放本次临时分支，检测完成后关闭进程管道；保留模型、提供商、思考强度及临时分支隔离检查。

## 0.3.0

- **左栏信息卡**：账号区上方显示当前对话最近响应的 Agent 速度（tok/s）与模型指纹，点击打开右侧统计。确认不符时指纹变红；过期、未收录和弱证据分别标注，支持深浅主题和窄栏。
- **信息统计重写**：概览、模型检测和历史三视图；参考 agent-speed、ModelTrace、is-gpt-nerfed，提供 Token/速度统计、数字指纹及模型、思考强度、窗口变化记录。[来源与许可证](../plugins/forge.information-stats/SOURCES.md)。指纹是概率诊断，不证明服务端身份；主动采样由用户手动启动并可能消耗模型额度，参考库未收录 `gpt-6.1-sol`。
- **记忆管理重写**：双目录检索、来源与分类筛选、排序、备注新建/重命名/删除、草稿保留及保存冲突保护；生成摘要和历史只读。
- **独立 500K 修复**：启动时生成专用模型目录，并传入原生后端及检测进程，仅覆盖 `gpt-6.1-sol`。本地协议验证报告 475,000 可用窗口；远端服务接受真实长输入仍取决于提供商。
- **Forge API 2**：能力声明与查询、具名 UI 插槽、组合包/profile、内置开发检查器、DSH 预构建客户端导入。内置插件与示例统一使用 API 2；API 1 插件保留清单读取及诊断，作者迁移后方可在 API 2 宿主中启用。见 [API 迁移说明](PLUGIN-API.md) 与 [组合包](BUNDLES.md)。
