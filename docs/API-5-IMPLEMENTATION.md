# Forge API 5 实施与验收

目标：补齐公共宿主服务、插件市场、会话与模型接口、后端服务和工具注册、执行钩子、流式取消、后台及定时任务、UI 扩展、文件与网络及凭据代理；保留 API 1–4 的原有行为。

## 实施顺序

1. 公共 SDK、权限/能力注册表、清单与类型：新增能力独立授权，旧插件不因升级自动获得历史、发送、模型或宿主 IO 权限。
2. 宿主服务与市场：复用既有画布/待办/技能/记忆/统计/协作及插件安装更新机制；增加受控目录、安装和管理。
3. 后端与扩展：显式可信 Node 子进程、声明式服务/工具/模型提供方/钩子、动态启停和资源注销；MCP 通过本机鉴权代理调用已授权插件工具。
4. 通信与任务：按窗口、插件指纹、frame、线程隔离请求；流式双向传输、实际取消、超时和背压；持久后台/定时任务。
5. UI 与迁移：实用的插槽、主题、快捷键、日志和开发示例；同步 API 5、版本、更新器和构建元数据。

## 验收

- 针对每类真实行为的定向测试：授权拒绝、跨插件/跨 frame/跨线程拒绝、取消与停用、提供方崩溃、模型与工具调用、任务重启、目录身份及文件修订、下载摘要及市场来源。
- SDK TypeScript 消费、API 1–4 兼容、流式通信和资源释放测试。
- 完整项目回归、UI 构建；隔离 UI/客户端验证可观测入口和新增贡献点，记录模拟服务与真实远端验证范围。
- 逐项记录功能落点和证据。新增接口不以登记成功代替实际执行成功；未验证或原生端不支持的行为明确报告。

## 分工

- 主代理：宿主集成、业务服务与 IO、市场、MCP 代理、UI、元数据、文档及整体验收。
- api5_sdk_transport：浏览器 SDK、TypeScript/Schema、RPC 流/取消及对应测试。
- api5_backend_runtime：Node 后端、服务/工具/提供方/钩子、任务与定时器及对应测试。

用户授权实施和 API 升级；本任务不包含 Git 提交、推送或正式客户端部署。

## 完成结果（2026-11-12）

Forge 已升级为 0.7.0 / API 5；上述五组实施工作均已落地。40 项新增权限、37 项能力、6 类钩子和 7 个插槽与 SDK、Schema 和运行时一致。保持 API 1–4 的原有协议；第三方插件显式声明的 Forge/Codex 范围仍严格校验。

| 机制 | 主要实现与验收 |
| --- | --- |
| 公共业务与会话 | `forge-api5.cjs` 接入真实服务；历史使用 `thread/turns/list`，发送接入原生请求，frame/指纹/线程/代次隔离和正文权限回归通过。 |
| 市场和权限审阅 | `forge-plugin-market.cjs` 提供多来源目录、搜索、真实安装、来源/身份/摘要/兼容校验；首次默认停用，第三方管理插件不能伪造人工审阅。服务消费范围变化重新审阅。 |
| 模型、后端、服务和工具 | 独立原生采样、声明式可信 Node 后端、跨插件服务、模型提供方、MCP 工具及有序钩子。真实 CLI 本地采样和原生 Code Mode → MCP → 后端工具调用均验证。 |
| 通信和任务 | 异步迭代、双向通道、取消/期限/背压，持久 job 与 at/every/时区 cron；配置重载和退出等待清理均有回归。 |
| 文件、网络和凭据 | 连接目录/当前工作区、路径与链接检查、身份及修订保护；HTTPS 来源和无重定向凭据代理；Windows 当前用户 DPAPI 往返通过。 |
| UI、开发与升级 | 7 个实际原生插槽、主题应用/恢复、快捷键、日志、类型/Schema、示例和教程；启动器、准备程序、更新器均迁移至 API 5。 |

完整 Node 回归 572/572，C# 更新器 45 项断言；隔离窗口 14 项检查通过、渲染错误 0。真实原生 CLI 的 3 次本地模拟请求覆盖流、用量、工具尝试停止和取消连接。证据汇总见 [验证记录](VALIDATION.md)。

Node 后端是显式授予的可信代码，独立进程不构成系统沙箱。原生发送有前后钩子；闭源 Codex 内部模型/工具循环不提供任意替换。DSH 服务端/Cordis 插件仍需迁移到 Forge 契约。市场默认条目不代表其当前发行版已兼容 0.7；安装始终以实际发布清单为准。
