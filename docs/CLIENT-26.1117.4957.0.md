# 官方客户端 26.1117.4957.0 适配

Forge 0.7.4 适配 Windows x64 客户端 `26.1117.4957.0`，内部发行版为 `26.1117.41037`。Forge API 保持 5。

## 官方包与适配

- [官方更新清单](https://persistent.oaistatic.com/codex-app-prod/windows-store-update.json)与微软商店香港、美国区均列出此版本。
- [官方 MSIX](https://persistent.oaistatic.com/codex-app-prod/releases/26.1117.4957.0/ChatGPT-x64.msix)：796,523,063 字节；SHA-256 为 `561f0b0c6edc4dbf5f00f33b86e0786ea59a0ff926759813b26770a0e8c4d963`。已验证有效签名、OpenAI.Codex 身份与 x64 架构。
- 新增独立 `nov23` 适配器，绑定原始 ASAR、EXE、37 个前端工厂及提示词预测模块摘要；保留旧版适配器。
- 工作区、设置导航与搜索重新接入新版模块。Forge 栏目参与标题搜索，原生详细设置搜索只查询其认识的栏目，避免未知栏目导致错误页。
- 保留官方压缩语言资源加载流程，在解码后的简体中文消息表中补充 Forge 文本。
- 覆盖 12 份速度选择工厂、13 份请求工厂，以及主进程和独立 app-server-host 的启动参数；保留原生账号及服务商限制。
- 更新标题生成的 MCP 配置补丁、原生预测优先策略和浏览器/电脑操作接入。GPT-6.2 模型、Sol 可选 500K、指纹库和插件 API 保持既有功能。

## 验证范围

适配阶段全量 Node 回归 601 项通过，0 失败、0 跳过。覆盖新增版本的 Fast / Ultrafast 权限、请求参数、工作区懒加载、设置搜索、后台模型目录和 MCP 参数，以及标题生成配置。

隔离客户端验证了 21 项不同界面行为：六个侧栏入口在未进入设置前可用；插件管理和升级工具栏；插件设置直达；500K 默认关闭及保存重开；模型显示；设置搜索、悬停、无结果、原生常规设置及普通导航；Sol 三种速度、Astra 切换与 Ultrafast、Terra 切换。Forge 页面保留在原窗口内。最终验收没有渲染错误。

模型后端复用同一官方包当天已完成的 6 次 localhost 模拟请求验证，Sol 500K 开关分别报告 258,400 / 475,000 可用 tokens，并覆盖 Standard、Fast、Ultrafast；Forge MCP 工具发现也已验证。

实际服务商加速、计费、长上下文请求、Pro 原生预测服务、真实浏览器/电脑操作及正式 MSI 安装/卸载不在本轮实测范围内。发布不替换或重启本机正式客户端。
